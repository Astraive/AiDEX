Step 1 chooses between a standard per-user target and a portable removable drive. Standard mode inspects the current user's local-data directory and prepares its `AiDEX` subdirectory without elevation. Portable mode uses the real volume list (`list_drives`) with label, root, attachment, filesystem, and free/total space; only removable media or USB fixed disks that are not the system drive can be selected, and installation stays at the drive root. Both choices create only AiDEX folders and a manifest; this build does not include the app bundle or components. Existing files are preserved.
