# Install step

Step 6: review the selected normal per-user or portable removable target, then run setup through `useInstallRun` (`../../lib/useInstallRun.ts`). Standard mode inspects and initializes the current user's local-data `AiDEX` directory with `inspect_normal_target` / `init_normal_target`; portable mode uses `inspect_drive` / `init_drive` and requires an eligible removable drive root. Both modes create only the manifest-declared folders and `aidex-drive.json`, preserve files, and never format or delete. The target is inspected again to verify the manifest. Copying the signed desktop bundle (issue #55; portable packaging issue #26), creating the vault on first launch, importing models (#15), and installing agents (#23, #24) remain unavailable or skipped, never simulated or reported as done. A failure stops the run with the backend error; retrying layout initialization is safe and idempotent.
