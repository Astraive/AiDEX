The glyph data is regenerated by reading each `icons/<name>.svg` file of the
package, keeping only its `<path>` elements (path data, fill rule, and opacity),
and taking the first solid fill of `icons/<name>-color.svg` as the brand color.
Colors too dark or too light to read on either theme are dropped so the glyph
inherits the surrounding text color.
